
# Wedding Invitation Website 💍

A responsive digital wedding invitation built using HTML, CSS, Bootstrap 5 and JavaScript.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- Google Fonts

## Project Structure

wedding-invitation/
- index.html
- css/style.css
- js/script.js
- assets/images/
- assets/music/
- README.md

## Run Locally

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open index.html using the Live Server extension.
4. View the website in your browser.

You can also open index.html directly in a browser.

## Customize Wedding Information

Edit index.html to change:
- Bride and groom names
- Wedding date
- Venue and address
- Muhurtham time
- Event details
- Gallery photographs

Edit js/script.js to change the countdown date.

Edit css/style.css to customize colors, fonts and layouts.

## Add Wedding Music

Place your own MP3 file here:

assets/music/wedding-music.mp3

The music button will allow visitors to play and pause the music.

## RSVP Note

The current RSVP form is a frontend demonstration. It does not save responses permanently or send them to the couple.

A backend or form service is needed to collect actual guest responses.

## Deploy on GitHub Pages

1. Create a GitHub repository named wedding-invitation.
2. Push all project files to the main branch.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and / (root).
7. Click Save.

Your website will be published at:

https://YOUR-USERNAME.github.io/wedding-invitation/

The GitHub repository and published website are separate experiences.

Enjoy your special day! ❤️
